Security

Responsible disclosure

If you believe you found a vulnerability, open a minimal report in the support tracker and ask for a private reporting route. Do not publish exploit details, credentials, personal data, or private Discord content.

In scope

Authorization bypass, cross-server data access, action-confirmation bypass, privilege escalation, token or credential exposure, injection that crosses an application trust boundary, and unintended destructive execution.

Safe testing

Test only accounts and servers you own or are explicitly authorized to test. Do not access other users' data, disrupt service, send spam, perform denial of service, or use automated high-volume scanning.

Design principles

The AI model proposes; application code authorizes and executes. Actions are allowlisted, schema-validated, permission-checked twice, requester-confirmed, idempotently claimed, and audited. Unsupported tools cannot be created through prompting.
