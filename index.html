Start with a sentence

Mention AsterByte, reply to it, use “AsterByte,” or a configured prefix. Say “starter pack” for a quick tour. Slash commands remain available.

Remember what matters

Catch up on a channel, extract action items, run saved workflows, and set durable reminders. Managers can opt into visible, time-limited scheduled digests.

Permission-aware

Discord permissions are checked before proposing an action and checked again immediately before execution.

Small, opt-in fun

Trivia, polls, dice, coin flips, and a daily conversation spark. No streak pressure, unsolicited pings, or fake activity. These tools use no AI quota.

Your provider. Clear limits.

The beta has a limited shared Groq account. Personal Groq and OpenRouter key support is implemented, with encrypted storage and no silent fallback to another account. Self-service connection currently works only for the operator on the bot's Mac; public HTTPS onboarding isn't deployed yet.

We use official APIs, not consumer chat logins, cookies, or subscription workarounds. Bot quotas and provider limits still apply. Understand accounts and privacy →

Support

For a question, privacy request, security report, or beta issue, open a ticket in the AsterByte support tracker. Do not include bot tokens, API keys, private message content, or other secrets.
